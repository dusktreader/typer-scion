# Quickstart

## Requirements

* Python 3.12 to 3.15


## Installation

This will install the latest release from pypi via uv:

```shell
uv add typer-scion
```


## Using

Here, you should add documentation about basic usage for your project!



## Run the demo

To see the features in action, you can run the demo in an isolated environment with `uv`:

```shell
uvx --from typer-scion typer-scion-demo
```

You can check out options available by passing `--help` to the command.
